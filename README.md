# Fix Happens

**Shit breaks. Fix Happens.**

Cross-platform field diagnostic system for macOS and Android.

## What it does
- Turns symptoms into structured troubleshooting cases
- Tracks evidence, hypotheses, and verification steps
- Stores commands, repair history, and knowledge packs
- Supports macOS desktop workflows and Android field workflows

## Planned modules
- macOS desktop app
- Android companion app
- Shared workflow engine
- SQLite persistence
- Knowledge packs for networking, HVAC, electrical, plumbing, and general repair

## Current status
Project foundation and architecture setup.
