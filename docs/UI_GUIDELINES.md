# Fix Happens UI Guidelines

## Visual Language
- Clear crystal glass surfaces
- Pink accent reserved for interactive elements
- Dark gradient workspace
- Large rounded corners
- Soft depth and blur

## Layout
- Left navigation
- Top search and status bar
- Main diagnostic workspace
- Evidence and command panels

## Interaction
- Fast transitions (200–300ms)
- Consistent spacing
- Accessible typography
- Keyboard-first desktop workflow
