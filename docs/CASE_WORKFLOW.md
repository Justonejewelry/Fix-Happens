# Case Workflow

1. Create Case
2. Gather Evidence
3. Generate Hypotheses
4. Rank by Confidence
5. Recommend Tests
6. Execute Tests
7. Verify Results
8. Close Case
9. Archive Knowledge

## Evidence Model
- Observation
- Command Output
- Log Entry
- Screenshot
- User Statement

## Case States
New
↓
Investigating
↓
Testing
↓
Repairing
↓
Verification
↓
Resolved
↓
Archived
