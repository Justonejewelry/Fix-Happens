# How to run Fix Happens

## macOS (Electron) — works today

**Requirements:** Node.js 18+ (includes npm)

```bash
git clone https://github.com/Justonejewelry/Fix-Happens.git
cd Fix-Happens
npm install
npm start
```

You should see the Liquid Glass **Case Workspace** window.

- **+ Create** / **Close** — manage cases
- Add evidence — hypotheses re-rank live
- **Solid surfaces** toggle — accessibility
- Badge shows **Core engine** when preload loads `core/diagnosticEngine.js`

Troubleshooting:
- If the window is blank, check the terminal for Electron errors.
- `npm start` must be run from the **repo root** (where `package.json` lives).
- Error map: **[TROUBLESHOOTING.md](TROUBLESHOOTING.md)**

## Android (Flutter) — one bootstrap step

The repo ships **Dart source** under `apps/android/lib/`.  
You still need the Android platform folder once (generated by Flutter).

**Requirements:**
- [Flutter SDK](https://docs.flutter.dev/get-started/install) (stable)
- Android Studio or cmdline-tools + an emulator/device

### First-time setup

```bash
cd apps/android
chmod +x tool/bootstrap.sh
./tool/bootstrap.sh
```

Or manually:

```bash
cd apps/android
flutter create . --project-name fix_happens --org com.fixhappens --platforms=android
flutter pub get
```

`flutter create` keeps existing `lib/` and `pubspec.yaml` and adds the `android/` platform project.

### Permissions (photos / camera)

After bootstrap, merge the snippet from `android_permissions_snippet.md` into:

`android/app/src/main/AndroidManifest.xml`

### Run

```bash
cd apps/android
flutter pub get
flutter run
```

You should see the **open cases** list → tap a case → workspace with evidence, hypotheses, verification, and photo capture.

### When something fails

```bash
cd apps/android
chmod +x tool/diagnose.sh && ./tool/diagnose.sh
flutter run -v 2>&1 | tee /tmp/fix-happens-flutter.log
```

Then match the error text in **[TROUBLESHOOTING.md](TROUBLESHOOTING.md)**.
